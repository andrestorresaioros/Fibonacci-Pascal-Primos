# Fibonacci, Pascal y Primos

Ejercicios en Python sobre tres problemas clásicos de algoritmia, cada uno en su propia carpeta.

## Contenido

- Fibonacci/ — generación de la serie de Fibonacci
- Pascal/ — construcción del triángulo de Pascal
- Primos/ — identificación y generación de números primos

## Objetivo

Practicar iteración, recursión y manejo de estructuras de datos sobre problemas numéricos conocidos.

## Ejecución

Requiere Python 3. Desde la raíz del repositorio:

    python Fibonacci/<archivo>.py

Sustituir la carpeta y el archivo según el ejercicio.
